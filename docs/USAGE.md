# GUI 사용 예시

현재 멤버는 기본 6명으로 시작하지만 **밴드 설정 → 멤버 선택 → 선택 멤버 삭제**를 반복해 1~5명 밴드로 운영할 수 있습니다. 삭제 확인창에서 현재 일정 응답과 곡 난이도·투표 제거 범위를 확인하세요. 확정된 계획의 당시 기록은 남고 마지막 1명은 삭제할 수 없습니다. 멤버를 다시 추가하면 기존 날짜와 곡은 미응답으로 시작합니다. 아래 Demo 설명은 6명으로 생성된 가상 샘플의 예시입니다.

발표 추천 실행: `.\run-gui.ps1 -Demo`. 2026-11-18 준비 기준 44일·8곡·2계획을 별도 파일에 저장해 뒀습니다. 남성 보컬은 응답 완료, 건반은 일부 미응답 상태입니다. 기준일+2일은 전원 가능, +1일은 5명 가능, +4일은 전원 불가, +6일은 3명 미응답입니다. 곡 1/2/5/6은 추천 대상, 3/7은 찬성 부족, 4/8은 투표 미완료입니다. 계획 목록에는 전원/부분 참석 예시가 한 개씩 있습니다. 편집·추가할 수 있도록 5개 중 2개만 채웠습니다. 일반 입력은 그대로이며 기존 샘플은 교체 전 파일을 보관했습니다.

2026-11-18 H35 기준. 실행 스크립트가 있는 폴더에서 `.\run-gui.ps1 -Demo`를 실행합니다. `.\run.ps1 -Demo`도 같은 GUI를 엽니다.

1. 왼쪽 사이드바의 BAND DECISION 로고와 일정 메뉴 사이에서 입력할 멤버를 고릅니다.
2. 일정에서 이번 달/다음 달 각각 이 달 전체 → 가능 적용으로 기본 응답을 넣습니다.
3. 불가능한 날은 하루 선택 또는 기간으로 선택하고 불가 적용합니다. 실수하면 마지막 응답 되돌리기를 사용합니다.
4. 다른 멤버 응답도 입력합니다. 개인 완료는 전체 기간 기준, 날짜 추천은 그 날짜의 전원 응답 기준입니다.
5. 곡·투표에서 곡을 등록하고 멤버별 찬반을 저장합니다. 반대 사유는 필수입니다.
6. 합주 계획 → 새 합주 만들기에서 날짜와 곡을 고릅니다. 부분 참석 여부와 최종 내용을 확인해 확정합니다.
7. 목록에서 확정 계획을 수정·삭제할 수 있습니다. 최대 5개입니다.
8. 하단 저장됨 시각을 확인한 후 종료·재실행하여 데이터가 유지되는지 확인합니다.

밴드 설정에는 실력 수정과 저장 실패 시 사용할 ‘저장 다시 시도’가 있습니다. 콘솔·수동 백업·복원은 제거했습니다. 자동 저장과 일정 응답 되돌리기는 유지합니다. 상세 규칙은 [README](../README.md)를 참고하세요.

2026-11-19 사용자 전달 안내: 구현 결과와 발표 시연은 `-Demo` 화면으로 보여주면 된다. 별도 발표 전용 기능이나 처음부터 모든 데이터를 새로 입력하는 시나리오는 준비 대상이 아니다. 시연 전에 Demo 파일의 날짜가 오늘 이후인지 확인하고, 필요한 경우 가상 데이터에서 날짜 응답·곡 투표·계획 확정의 연결을 보여준다. 아래 직접 시연 점검은 실제 수행 여부를 기록하기 위한 목록이며 발표에서 모든 항목을 하나씩 시연해야 한다는 뜻은 아니다.

## 직접 시연 점검 — 미완료

- [ ] 하루·기간·전체 선택, 응답 적용과 되돌리기.
- [ ] 곡 등록·수정·삭제와 투표 사유 입력.
- [ ] 계획 부분 참석/최종 확인의 승인·취소, 수정·삭제.
- [ ] 종료·재실행 후 데이터 유지.
- [ ] 작은 창·큰 글자와 다른 PC에서 실행.

이 목록은 자동 검사와 별도입니다. 직접 수행한 경우만 결과를 검증 기록에 추가합니다.
