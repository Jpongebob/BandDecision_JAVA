# BandDecision

고정 6파트 밴드의 합주 날짜·곡을 추천하고 담당자가 직접 계획을 확정하는 Java Swing 프로그램입니다. JDK 17 이상, 외부 라이브러리 없이 실행합니다.

## 실행

발표용으로 더 풍부한 예시를 보려면 **`.\run-gui.ps1 -Demo`**을 실행하세요. 일반 데이터와 별개인 `data/demo.properties`를 사용하며 최초 실행일~다음 달 말일 일정, 곡 8개, 확정 계획 2개를 생성합니다. 재실행은 변경 내용을 유지합니다. 이번 준비 데이터는 2026-11-18~12-31의 44일입니다. 개인 응답 완료/미완료, 전원 가능/불가/부분 참석/미응답, 추천 곡 4개와 보류 곡 4개를 비교할 수 있습니다. 가상의 곡·일정입니다. 오래된 발표 파일은 날짜가 자동으로 이동하지 않습니다.

GitHub에서 내려받으려면:

```powershell
git clone https://github.com/Jpongebob/BandDecision_JAVA.git
cd BandDecision_JAVA
.\run-gui.ps1 -Demo
```

JDK 17 이상이 필요합니다. 개인 저장 데이터와 컴파일 결과는 저장소에 포함하지 않으며 최초 실행 시 생성합니다.

실행 스크립트가 있는 BandDecision 폴더에서:

```powershell
.\run.ps1
# 또는
.\run-gui.ps1
# 실행일 기준 샘플(처음 실행할 때 생성)
.\run.ps1 -Demo
# 자동 검사
.\build.ps1 -Test
```

두 실행 스크립트 모두 GUI를 엽니다. 콘솔 메뉴는 제거했습니다. 과거 -Gui/--gui 인자는 호환상 허용되지만 필요하지 않습니다. IntelliJ에서는 Main을 실행하고 샘플은 --demo 인자를 줍니다. java와 javac가 모두 필요하며 빌드는 --release 17을 사용합니다. PowerShell 실행 정책이 막으면 `powershell -NoProfile -ExecutionPolicy Bypass -File .\run-gui.ps1`로 해당 실행에만 옵션을 지정할 수 있습니다.

## 사용 순서

상단 입력할 멤버는 일정·투표가 공유합니다. 왼쪽 메뉴는 일정 / 곡·투표 / 합주 계획, 아래는 밴드 설정입니다.

- 일정: 오늘부터 다음 달 말일까지 달력에서 바로 응답합니다. 하루 선택은 클릭한 날짜 하나로 교체하고, 기간으로는 시작/종료일을 클릭하며 월 경계를 넘을 수 있습니다. 이 달 전체는 표시 월의 지난 날짜를 제외해 선택하며 다시 누르면 해제합니다. 선택만으로 응답이 바뀌지는 않습니다.
- 가능 적용 / 불가 적용 / 미응답 적용은 선택 날짜에 상단 멤버의 응답을 반영합니다. 오른쪽 표의 직접 수정은 표시 날짜 하루만 바꿉니다. 불가 사유는 선택 사항이고 공란 적용 시 기존 불가 사유를 유지하거나 기본 문구를 씁니다.
- 개인 완료는 오늘~다음 달 말일 전체에 답했는지 판단합니다. 이번 달/다음 달 각각 전체 적용 후 예외 날짜를 바꾸면 편합니다. 날짜 추천은 별도로 해당 날짜 6명 전원의 응답이 모이면 계산합니다.
- 달력 색상: 개인 가능 파랑, 불가 빨강, 전원 가능 초록. 체크·테두리는 현재 선택 범위입니다. 합주 가능 표시는 계획 확정과 다릅니다. 지난 날짜는 읽기 전용이며 범위 밖의 기존 기록도 보존합니다.
- 마지막 응답 되돌리기는 실행 중 마지막 일정 변경을 한 단계 되돌리고 저장합니다. 기간 적용·사유·새 기록 생성까지 복구하며 곡과 계획은 바꾸지 않습니다.
- 곡·투표: 후보곡 등록·수정·삭제, 6파트 난이도와 투표 조회. 상단 멤버의 찬성/반대와 사유를 입력하고 내 투표 저장을 누릅니다. 반대 사유는 필수입니다. 곡 수정은 ID/기존 투표를 유지하고 삭제는 해당 곡 투표도 제거합니다.
- 합주 계획: 새 합주 만들기에서 추천 날짜와 곡을 고릅니다. 여러 곡은 Ctrl/Shift로 선택합니다. 부분 참석 경고·최종 확인 후 확정합니다. 최대 5개이며 목록에서 수정/삭제합니다. 이후 원본 곡·응답 변경이 이미 확정된 기록을 자동으로 바꾸지 않습니다.

확정한 계획의 날짜는 달력에 **합주 확정**으로 표시합니다. 날짜를 선택하면 오른쪽 상태에 계획 번호가 나오고, 날짜 카드에 마우스를 올려도 번호를 볼 수 있습니다. 같은 날짜에 계획이 여러 개면 번호를 함께 표시하며 수정·삭제하면 달력도 갱신됩니다. 달력의 응답 색과 선택 표시는 그대로 사용합니다.
- 밴드 설정: 파트 실력 1~5 수정과 지금 저장. 자동 저장 실패 시 지금 저장으로 재시도할 수 있습니다. 수동 백업·복원 메뉴는 제거했습니다.

날짜는 전원 응답·참석 가능 1명 이상을 인원 내림차순/날짜 오름차순으로 추천합니다. 곡은 전원 투표·찬성 4명 이상이면 추천하며 부담은 max(0, 난이도−실력), 점수는 3×찬성−2×총 부담입니다. 동점은 찬성 수, 부담, 곡 ID 순으로 정렬합니다.

기본 글자 크기는 90%, A-/A+로 90~140% 조절합니다. 설치된 Noto Sans KR을 우선 사용하고 맑은 고딕 등으로 대체합니다. 작은 창에서는 작업 영역을 스크롤합니다.

## 자동 저장

변경은 UTF-8 파일에 자동 저장되고 재실행 시 읽습니다. 일반은 data/banddecision.properties, 샘플은 data/demo.properties입니다. 샘플도 재실행 시 이전 내용을 유지합니다. 동시에 여러 창/프로세스로 같은 파일을 편집하지 마세요.

저장 성공은 하단 시각으로, 실패는 붉은 안내로 표시합니다. 실패한 변경은 현재 메모리에 남습니다. 손상 파일은 실행 시 오류를 안내합니다. 기존 v1/v2 파일 읽기와 변환 시 원본 보관은 유지하며 새 저장은 v3입니다. 수동 백업 메뉴 제거가 기존 저장 파일 삭제나 자동 저장 제거를 뜻하지 않습니다.
